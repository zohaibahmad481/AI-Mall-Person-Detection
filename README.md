# 🏬 AI Mall Person Detection System

An AI-powered real-time person detection system designed for mall and retail CCTV surveillance.

The system uses deep learning and computer vision to automatically identify people from CCTV footage or live camera streams. Detected persons are highlighted using bounding boxes along with confidence scores.

---

## 🚀 Project Overview

Modern shopping malls contain multiple CCTV cameras that continuously monitor large areas.

Manually monitoring every camera is difficult and time-consuming.

This project provides an AI-based solution that automatically analyzes CCTV video and detects people in real time.

The system can be used for:

- Mall surveillance
- Retail store monitoring
- Crowd monitoring
- Customer counting
- Security systems
- CCTV video analytics
- Smart surveillance applications

---
